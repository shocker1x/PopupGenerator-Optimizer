# Demo Recording Script

This outline is for a future recording. Use a configured local or deployed stack and real observed behavior; do not narrate synthetic seed values as real campaign performance.

1. Sign in or create a local demo account.
2. Enter a public website URL and show the extracted site snapshot. Point out that the system uses the observed promotion when one exists and flags new offer ideas for owner approval.
3. Show the three generated directions and switch between them in the preview.
4. Edit a headline, color, and trigger. Save, then ask for a focused regeneration and verify unrelated fields remain unchanged.
5. Upload a small test image, publish a version, and show the embed snippet.
6. Open the host test page and demonstrate the popup, close behavior, and signup consent.
7. Return to the campaign metrics. Explain impressions, signups, dismissals, credible intervals, and the sample-size gate. Use the synthetic seed script only if clearly labeled as demo data.
8. End by showing the security/privacy boundaries and known limitations listed in the README.
